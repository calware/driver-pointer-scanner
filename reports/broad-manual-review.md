# Broader writable-callback review (offline)

The broader rule asks whether a recovered WDM `IRP_MJ_DEVICE_CONTROL` or KMDF `EvtIoDeviceControl` path can reach an indirect call through a writable image slot. It does **not** require `SystemBuffer` or a retrieved KMDF input buffer to be passed as a callback argument. A hypothetical separate kernel-memory overwrite is assumed; this scan does not identify a writer controlled by user mode.

The 522-image pass yielded 51 images with a SAT partial path and slot-initialization evidence, 2 with a SAT partial path but unresolved initialization, 93 rooted MAY slot-call leads, 60 with no such image slot in converged modeled paths, and 316 inconclusive. Of the 53 SAT partial images, 26 had a `Running` service in the read-only inventory snapshot. Forty-three SAT partial images had a slot directly written from a `MmGetSystemRoutineAddress("WmiTraceMessage")` lookup. These counts are image-level; multiple calls often share one slot.

The broad path refiner records a SAT partial modeled path. The wrapper calls the saved pointer at `0x310a2`. The modeled path has two represented predicates and a SAT partial witness. | The service was stopped; a device instance, valid user handle, actual request path, and live pointer state were not observed. |
| `kbdclass.sys` | Running service. Slot `0xb108` is written at `0xe534` from a dynamic `WmiTraceMessage` lookup. A device-control-rooted chain reaches guarded call `0x1b8f` with seven modeled predicates on one SAT partial path. | The namespace strings do not establish device ACLs or a successful `CreateFile`/`DeviceIoControl` call; trace state and other branches remain unproved. |

These are materially stronger **broad static leads** than the earlier `SystemBuffer`-as-callback-argument results. In particular, `bfs.sys` and `amdsbs.sys` illustrate locally installed callbacks and saved dispatch pointers; the tracing examples illustrate optional dynamically resolved callbacks. The report does not call any of them a confirmed live user-to-kernel execution path. The source and sink disassembly excerpts are in `reports/bfs-broad-*.txt`, `reports/amdsbs-broad-*.txt`, `reports/kbdclass-broad-*.txt`, `reports/bttflt-broad-*.txt`, and `reports/AsusSAIO-broad-*.txt`.

The machine-readable `reports/broad-installed-reviewed.json` provides every callsite, slot RVA, initial pointer state, direct writer, writer-source hint, static call chain, partial solver result, narrow-variant status, and service-state snapshot. `ROOTED_MAY_SLOT_CALL` entries are review leads; a fixed-point join can combine infeasible states. `PATH_SAT_WITH_INITIALIZATION_EVIDENCE` is stronger but remains a partial static model. `reports/broad-integrity.json` confirms all 522 installed image hashes stayed unchanged during this pass.
